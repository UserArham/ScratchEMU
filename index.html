Scratch Program Loader

An open source Scratch emulator that can run older versions of Scratch using Smalltalk and SqueakJS. This project needs JavaScript enabled; or else the page will conflict to the browser like Chrome. Scratch 2.0 cannot run inside this page due to the end-of-life of Adobe Flash Player (No, not actual Flash, I said Flash for Web Browsers.). Use the "Run Scratch 2.0" button to open it in a new tab. You can try and use these emulations in this iframe if it has a bug that prevents them from opening in a new tab, though it's older: Scratch 1.4 Beta, Scratch 1.4 Release Candidate, Scratch 1.4, Scratch 1.4.0.1, and Scratch 1.4.0.7. The last version to support the emulator was Scratch 1.4.0.7, because of Smalltalk issues with Scratch 2.0 (which cannot run unless you use Ruffle), but however I ported the 2.0 version! Use the button below to use Scratch 2.0. I droppped support to Internet Explorer because their JavaScript do not support const.
This content is exclusively on Chrome, Safari, Firefox, Edge, and more. However this was not supported in older versions because the website supports JS.
Unsupported versions: Internet Explorer (IE) versions, Safari 5-9, Opera 12, Opera Mini, Android Browser 4.3 and some older versions of Android WebView.
